# Code of Conduct

pwsh-termux is a small technical project. Everyone taking part (issues, pull requests, discussions) keeps it a place where people can work without harassment.

## Expected

- Be respectful and assume good faith.
- Keep feedback about the work, not the person.
- Accept that the maintainer decides what the project packages ([governance](docs/markDown/engineering/governance.md)).

## Not acceptable

- Harassment, insults, threats or discrimination of any kind.
- Publishing other people's private information.
- Spam, including links added only for search ranking.
- Anything a reasonable person would call unprofessional in a project setting.

## Scope

The repository, its issues and pull requests, the website, and any space where someone speaks for the project.

## Reporting and enforcement

Report privately through [GitHub's private reporting](https://github.com/EliorMachlev/pwsh-termux/security/advisories/new), marked as a conduct report, or in an issue if the matter is not sensitive. The maintainer acknowledges a report within 7 days, decides what to do and tells the reporter the outcome. Consequences range from a warning to removing comments and blocking an account from the repository.
