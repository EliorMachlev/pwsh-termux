# Code of Conduct

pwsh-termux is a small technical project. Everyone who takes part in it (issues, pull requests, discussions) is expected to keep it a place where people can work without being harassed.

## Expected

- Be respectful and assume good faith.
- Keep feedback about the work, not the person.
- Accept that the maintainer decides what the project packages and what it does not ([governance](docs/markDown/engineering/governance.md)).

## Not acceptable

- Harassment, insults, threats, or discrimination of any kind.
- Publishing other people's private information.
- Spam, including links added only for search ranking.
- Anything else that a reasonable person would call unprofessional in a project setting.

## Scope

This applies to the repository, its issues and pull requests, the website, and any space where someone speaks for the project.

## Reporting and enforcement

Report a problem privately through [GitHub's private reporting](https://github.com/EliorMachlev/pwsh-termux/security/advisories/new), marking it as a conduct report, or by opening an issue if the matter is not sensitive. The maintainer will acknowledge a report within 7 days, decide what to do, and tell the reporter the outcome. Consequences range from a warning to removing comments and blocking an account from the repository.

Vulnerabilities are a separate matter: see [SECURITY.md](SECURITY.md).
