Privacy

pwsh-termux collects nothing about you. This page is the short version; the full policy is on GitHub.

This website and the apt repository

  • No cookies, no analytics, no advertising, no fonts or scripts from other sites, and no JavaScript at all.
  • No accounts, and no forms.
  • The site is hosted by GitHub Pages and its domain is served through DNS at Cloudflare. They may log requests (such as your IP address) under their own policies. The maintainer does not receive those logs.

The packages

  • The package scripts send nothing anywhere when you install or run PowerShell.
  • PowerShell itself is Microsoft’s software and behaves as Microsoft built it: it collects telemetry unless you opt out, and it may check for new versions. How to turn both off.

Contact

Questions: GitHub issues. Security problems: report them privately.
