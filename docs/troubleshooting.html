If something goes wrong

Find the message pkg printed, and what to do about it.

Key and signature errors

  • NO_PUBKEY, or the repository is not signed. The key is missing, empty or outdated: a key added by hand is not updated by pkg upgrade, and a device that misses a whole 180-day rotation keeps only the old key. Repeat the set-up, or download the key again and check it is not an error page. Then compare the fingerprints.

Package not found

  • Unable to locate package pwsh. The keyring package is missing (the source line comes with it), or pkg update was not run afterwards. Repeat the set-up.
  • Unable to locate package pwsh-preview. No preview is newer than stable right now. That is normal; see preview.
  • Unable to locate package glibc-repo. Termux’s package lists are old or on an outdated mirror. Run pkg update (or termux-change-repo), then the set-up again.
  • depends on glibc, but it is not installable. Run pkg install glibc-repo, then pkg update.

Wrong device

  • No installation candidate, or package architecture (aarch64) does not match system. uname -m must print aarch64. A 32-bit Termux (armv7l, armv8l) or an x86 device cannot run these packages. On a 64-bit phone, make sure Termux is the arm64-v8a build: dpkg --print-architecture prints aarch64.

Expired or not-yet-valid index

  • Release file … is expired. The index is valid for 14 days and re-signed daily. If the build has been broken for longer, apt refuses the old index rather than serve stale packages. PowerShell keeps working and updates resume once the index is re-signed. A device clock far ahead causes the same error: check the date in Android’s settings. If it lasts more than a day or two, look at the issues.
  • Release file … is not valid yet. Your clock is behind. Set the date and time automatically in Android’s settings.

PowerShell will not run

  • pwsh cannot execute, or a library is missing. Reinstall it. If that fails, open an issue with the output of the second command.
pkg install --reinstall pwsh
pkg list-installed | grep -E 'glibc|icu|pwsh'
