Install

One line, then pkg keeps PowerShell up to date.

Requirements

  • Termux on an arm64 (aarch64) device. Check with uname -m.
  • The Termux glibc repository, which provides the glibc libraries PowerShell needs. The line below enables it.
  • About 200 MB of free space (the package is about 50 MB to download).

Install

pkg install -y glibc-repo && \
curl -fsSL https://pwsh-termux.machlev.org/pwsh-termux-keyring.deb -o $TMPDIR/pwsh-termux-keyring.deb && \
dpkg -i $TMPDIR/pwsh-termux-keyring.deb && \
pkg update && pkg install pwsh

The second command downloads pwsh-termux-keyring, a small package with the repository’s public signing key and its apt source. The key goes to $PREFIX/share/keyrings/, not to apt’s global trust store, and the source names it with signed-by, so apt trusts it for this repository only. pkg then checks every later download against it; pkg remove pwsh-termux-keyring undoes it. Then run it:

pwsh
$PSVersionTable.PSVersion

For the preview channel, pkg install pwsh-preview installs pwsh-preview next to pwsh. It only exists while Microsoft’s newest preview is newer than the newest stable release.

Check the signing key

The file holds two keys. The first signs the repository; the second is an offline recovery key that only signs to move users to a new key if the first is ever lost or stolen. Compare both fingerprints. Compare it with the one in the security policy on GitHub, which is a separate channel, or with the key attached to each release:

7086 C70B 4A25 576F E0C0  CE77 E43F B41F 02D0 1FC8   signing key
937A 3D41 5103 CFF8 9DCD  A982 A4B4 5397 EEB6 D752   recovery key

To print it yourself:

pkg install gnupg
gpg --show-keys $PREFIX/share/keyrings/pwsh-termux-archive-keyring.gpg

Optionally, check where the package was built. Each pwsh-termux-keyring.deb has a signed build provenance from this project’s workflow; with the GitHub CLI (pkg install gh, signed in):

gh attestation verify $TMPDIR/pwsh-termux-keyring.deb --repo EliorMachlev/pwsh-termux \
  --signer-workflow EliorMachlev/pwsh-termux/.github/workflows/build-packages.yaml

Add the key by hand instead

If you would rather not install a package for it, these commands write the same two files with the same content:

mkdir -p $PREFIX/share/keyrings
curl -fsSL https://pwsh-termux.machlev.org/pwsh-termux.gpg \
  -o $PREFIX/share/keyrings/pwsh-termux-archive-keyring.gpg
echo "deb [signed-by=$PREFIX/share/keyrings/pwsh-termux-archive-keyring.gpg] https://pwsh-termux.machlev.org stable main" \
  > $PREFIX/etc/apt/sources.list.d/pwsh-termux.list
pkg update
pkg install pwsh

A key added by hand is not updated by pkg upgrade. When the key is rotated, download it again (the security policy announces it), or install the keyring package.

Update and remove

pkg upgrade            # updates everything, including pwsh and the key package
pkg remove pwsh        # remove PowerShell

To also drop the repository: pkg remove pwsh-termux-keyring, which removes the key and the source. If you added them by hand, delete $PREFIX/etc/apt/sources.list.d/pwsh-termux.list and $PREFIX/share/keyrings/pwsh-termux-archive-keyring.gpg.

If something goes wrong

SymptomCause and fix
pkg update says NO_PUBKEY or the repository is not signedThe key is missing, empty or outdated. Run the install line again; if you added the key by hand, download it again and check the file is not an error page.
Unable to locate package pwshThe keyring package is not installed (the source line comes with it), or pkg update was not run afterwards.
depends on glibc, but it is not installableThe glibc repository is not enabled: pkg install glibc-repo, then pkg update.
Installed but pwsh says it cannot execute or a library is missingRun pkg install --reinstall pwsh; if it persists, open an issue with the output of pkg list-installed | grep -E 'glibc|icu|pwsh'.

About PowerShell’s own behavior

This package does not change PowerShell. Microsoft’s build collects usage telemetry unless you opt out, and it can print a notice about newer versions. To turn both off, add to ~/.bashrc (or your shell’s file):

export POWERSHELL_TELEMETRY_OPTOUT=1
export POWERSHELL_UPDATECHECK=Off
