Install guide

Install

Add the repository once, then pkg installs and updates PowerShell like any other package.

Before you start

You need Termux on a 64-bit Arm phone and about 200 MB of free space. uname -m must print aarch64:

uname -m

Step 1

Set up the repository (once)

Stable and preview both need this. It enables Termux’s glibc repository and installs pwsh-termux-keyring: the public signing key and the apt source, trusted for this repository only. pkg then checks every later download against it.

pkg install -y glibc-repo && \
curl -fsSL https://pwsh-termux.machlev.org/pwsh-termux-keyring.deb -o "$TMPDIR/pwsh-termux-keyring.deb" && \
dpkg -i "$TMPDIR/pwsh-termux-keyring.deb" && \
pkg update

Tap or click a command once to select all of it, then copy it.

The versions the repository serves now are in its releases.

Prefer not to install a package for the key? Add it by hand.

Step 2

Stable

Pick this unless you want the preview. pwsh is the highest stable PowerShell 7 release.

pkg install pwsh

Start it, then print its version:

pwsh
$PSVersionTable.PSVersion

Step 3, optional

Preview

pwsh-preview is the newest preview or release candidate. Expect rough edges.

  • It exists only while the newest preview is newer than stable; otherwise pkg install says Unable to locate package.
  • It installs beside pwsh, as its own command. You can have both.
  • It never turns into stable: when the final release ships, install pwsh.
apt-cache policy pwsh pwsh-preview
pkg install pwsh-preview
pwsh-preview

Update

pkg upgrade updates pwsh, pwsh-preview and the keyring with everything else. A new PowerShell release arrives with the next daily run after Microsoft publishes it.

pkg upgrade

Uninstall

pkg remove pwsh
pkg remove pwsh-preview    # only if installed
pkg remove pwsh-termux-keyring
pkg update

Removing the keyring deletes the key and the apt source. If you added them by hand, delete the files yourself:

rm "$PREFIX/share/keyrings/pwsh-termux-archive-keyring.gpg" "$PREFIX/etc/apt/sources.list.d/pwsh-termux.list"

Your profile and modules in ~/.config/powershell and ~/.local/share/powershell stay; delete them for a clean slate.

Turn off Microsoft’s telemetry

This package does not change PowerShell. Microsoft’s build collects usage telemetry and checks for new versions unless you opt out. Append these to ~/.bashrc (or your shell’s startup file) and export them in the current shell:

echo 'export POWERSHELL_TELEMETRY_OPTOUT=1' >> ~/.bashrc
echo 'export POWERSHELL_UPDATECHECK=Off' >> ~/.bashrc
export POWERSHELL_TELEMETRY_OPTOUT=1
export POWERSHELL_UPDATECHECK=Off
