Unofficial apt repository

PowerShell 7 for Termux, with pkg.

Termux does not ship PowerShell. This apt repository follows Microsoft’s releases, checks each against Microsoft’s published hash, makes it run on Termux’s glibc and signs it. You install and update it like any other package.

Install Source on GitHub

Quick start

Four commands. One package.

You need Termux on an arm64 (aarch64) phone. Copy and run:

pkg install -y glibc-repo && \
curl -fsSL https://pwsh-termux.machlev.org/pwsh-termux-keyring.deb -o "$TMPDIR/pwsh-termux-keyring.deb" && \
dpkg -i "$TMPDIR/pwsh-termux-keyring.deb" && \
pkg update && \
pkg install pwsh

Tap or click the command once to select all of it, then copy it.

Then start PowerShell:

pwsh

The versions the repository serves now are in its releases.

How it works

From Microsoft’s release to your phone.

A daily workflow follows Microsoft’s releases, so pkg upgrade brings new ones in. Each step lights up in turn.

Diagram source (Mermaid) 
flowchart TD
    A["Microsoft publishes<br/>PowerShell 7 releases on GitHub"]
    B["Choose releases<br/>highest stable, plus a newer preview"]
    C["Verify<br/>SHA-256 must match hashes.sha256"]
    D["Patch and package<br/>Termux glibc loader, build the .deb"]
    E["Sign<br/>apt index signed with Ed25519"]
    F["Publish<br/>GitHub Pages and release assets"]
    G["Your phone<br/>pkg update, pkg upgrade"]
    A --> B --> C --> D --> E --> F --> G

Trust

Why trust it

Verified

Every download is checked against the SHA-256 in Microsoft’s own hashes.sha256 before it is packaged.

Signed

The index is signed with an Ed25519 key that apt checks on every pkg update. Check it yourself.

Made for Termux

Patched at build time for Termux’s glibc loader: no proot, no launcher.

Open and archived

The scripts are public and every .deb is kept as a GitHub release asset.

Unofficial. This is a community repackaging, not a Microsoft product, and Microsoft does not support it. Report problems with the packaging in this project’s issues, and problems with PowerShell itself to Microsoft.
