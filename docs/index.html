PowerShell 7 for Termux, with pkg.

An apt repository that follows Microsoft’s PowerShell releases, checks each one against Microsoft’s published hash, makes it run on Termux’s glibc, signs it, and publishes it. You install and update it like any other package.

Install Source on GitHub 
pkg install -y glibc-repo && \
curl -fsSL https://pwsh-termux.machlev.org/pwsh-termux-keyring.deb -o $TMPDIR/pwsh-termux-keyring.deb && \
dpkg -i $TMPDIR/pwsh-termux-keyring.deb && \
pkg update && pkg install pwsh

Tap or click the command once to select all of it, then copy it.

The versions the repository serves now are in its releases.

Needs Termux on an arm64 (aarch64) device. The line also enables the glibc repository and installs the repository’s signing key and source as one package, trusted for this repository only. The fingerprint check and a manual alternative →

What you get

Stable and preview

pwsh follows Microsoft’s newest stable release; pwsh-preview follows the newest preview or release candidate, when one is newer than stable.

Updated by itself

A daily workflow looks for new releases, so pkg upgrade brings them in, usually within a day of Microsoft publishing.

Verified

Every download is checked against the SHA-256 in Microsoft’s own hashes.sha256 before it is packaged.

Signed

The repository index is signed with an Ed25519 key; apt checks it on every pkg update.

Made for Termux

The binary is patched to use Termux’s glibc loader, so it runs directly: no proot, no extra launcher.

Open and archived

The scripts are public, and every built .deb is kept as a GitHub release asset.
